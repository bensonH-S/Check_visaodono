========================================
  MERIDIAN BK OFFICE — KIT PC GERÊNCIA
========================================

COMO FUNCIONA (firewall-friendly)
  1) Neste PC: Chrome baixa o Excel do BK Office (IP Brasil)
  2) Envia o arquivo por HTTPS (porta 443) para o Meridian
  3) O SERVIDOR grava no banco — a loja NÃO precisa abrir 5432

SEGURANÇA
  - Sem config.env / sem senha de banco no PC
  - Cofre AES: data\vault.dat
  - Token do kit no header X-Meridian-Kit-Token
  - Launcher: MeridianBkSync.exe

INSTALAR
  1) Copie a pasta para o PC (melhor C:\Meridian-BKOffice-Gerencia)
  2) TESTAR-UMA-VEZ.bat  → deve sair TESTE OK
  3) INSTALAR.bat

No VPS (.env) obrigatório:
  BKOFFICE_KIT_TOKEN=<mesmo do build>
  BKOFFICE_SERVER_SYNC=0
  + deploy da tag com rota /public/kit/...

LOGS: Logs\bkoffice-python-service.log
